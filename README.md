# Boat-Autopilot-Controller
PCB for a small boat autopilot system. Collects sensor data and drives actuators to maintain set course/position.

<img width="723" height="352" alt="scr2" src="https://github.com/user-attachments/assets/7c9c49ac-28a8-4546-bb2b-15cd7e80c14e" />

## Main Features
- STM32WB55 – main MCU with BLE
- MAX-M10S – GNSS positioning
- TMC2208 – stepper motor driver
- LIS3MDL – magnetometer (compass)
- AS5600 connector – absolute encoder input
- DC motor controller connector
